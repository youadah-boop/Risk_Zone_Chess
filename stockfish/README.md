# Stockfish WebAssembly Runtime

This directory is reserved for the Stockfish WebAssembly distribution used by
Risk Zone Chess.

Expected files:

```text
stockfish-18-lite-single.js
stockfish-18-lite-single.wasm
```

The application loads the local Worker from:

```text
stockfish/stockfish-18-lite-single.js
```
